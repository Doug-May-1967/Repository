Astrodynamics — Original Research

A conical reference frame for orbital mechanics

A fresh analysis of elliptical, parabolic, and hyperbolic orbits — combining geometry, mechanics, and derivations from fundamental principles into results not previously disclosed.

Goals

  • Common reference frame construction across all conic orbit types
  • Simplified reference frame translation
  • Simplified time-position equations
  • Presentation accessible at an undergraduate level
This site tracks ongoing research: a common conical frame that sits inside the classical spherical reference frame, in which elliptical orbits occupy a fixed 45° half-angle cone and hyperbolic orbits occupy cones whose half-angle varies with eccentricity.

Where to start

Background covers the published work this builds on. Framework introduces the conical reference frame itself. Elliptical Orbits and Hyperbolic Orbits summarize results for each family.
